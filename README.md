## 🎯 Objetivos de la asignatura

- Comprender los conceptos básicos de la programación y la lógica algorítmica.
- Diseñar algoritmos mediante pseudocódigo y diagramas de flujo.
- Manejar variables, tipos de datos, operadores y expresiones.
- Utilizar estructuras de control (condicionales y bucles).
- Dividir los problemas en funciones/métodos reutilizables.
- Trabajar con estructuras de datos básicas (arrays, listas, cadenas).
- Depurar y probar programas de forma sistemática.
- Introducirse en la programación orientada a objetos.

## 🚀 Cómo ejecutar los ejercicios

```bash

# 3. Ejecutarlo
```

## 🤝 Buenas prácticas

- Nombra variables y métodos de forma clara y consistente.
- Comenta el código cuando aporte valor, no de forma redundante.
- Haz commits pequeños con mensajes descriptivos.
- Prueba cada programa con distintos casos de entrada.
- No copies código sin entenderlo.
